# dsh-trace/v1

[English](v1.md) · **中文**

可选的 A2A 扩展：有界、脱敏的工具调用观察。

- **URI：** `https://github.com/hanphone/dsh-a2a/blob/main/docs/extensions/dsh-trace/v1.md`
- **required：** 否
- **载体：** 仅 `metadata`
- **默认：** 关闭

该扩展不改变任务的交付物：不新增 artifact，不修改 `Task.history`，出站工具渲染器也
不会读取它。

## 激活

只有当实例策略允许时，agent 才在 `AgentCard.capabilities.extensions` 中宣告该扩展。
客户端按请求激活：

```http
A2A-Extensions: https://github.com/hanphone/dsh-a2a/blob/main/docs/extensions/dsh-trace/v1.md
```

成功响应会在同名 header 中回显已激活的 URI。不允许该扩展的 server 会忽略请求
（因为扩展是可选的）。

## 数据

实时观察增量放在 `TaskStatusUpdateEvent.metadata[URI]`：

```json
{
  "event": {
    "callId": "call-1",
    "tool": "read_file",
    "phase": "start",
    "status": "running",
    "argsPreview": "{\"path\":\"a.txt\"}",
    "timestamp": "2026-10-25T10:00:00.000Z"
  }
}
```

落定任务在 `Task.metadata[URI]` 中携带有界摘要：

```json
{
  "calls": [
    {
      "callId": "call-1",
      "tool": "read_file",
      "phase": "start",
      "status": "running",
      "argsPreview": "{\"path\":\"a.txt\"}",
      "timestamp": "2026-10-25T10:00:00.000Z"
    },
    {
      "callId": "call-1",
      "tool": "read_file",
      "phase": "end",
      "status": "ok",
      "durationMs": 12,
      "timestamp": "2026-10-25T10:00:00.012Z"
    }
  ]
}
```

### 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `callId` | string | 工具调用关联 id |
| `tool` | string | 工具名 |
| `phase` | `start` \| `end` | 观察阶段 |
| `status` | `running` \| `ok` \| `error` \| `unknown` | `running` 只出现在 start；没有 result 就结束时为 `unknown` |
| `durationMs` | integer ≥ 0，可选 | 由会话事件时间计算的耗时 |
| `argsPreview` | string，可选 | 脱敏、截断后的参数摘要；只出现在 start |
| `timestamp` | ISO 8601 string | 事件时间 |
| `calls` | array | 持久摘要；最多 64 条观察 |
| `truncated` | boolean，可选 | 摘要丢弃了更早的观察 |

## 隐私与边界

- 永不包含原始工具参数、工具结果、文件内容或 reasoning。
- `argsPreview` 会脱敏 token/secret/password/api-key/authorization/cookie/
  credential/private-key 等键，并把序列化值截断到 200 字符。
- 无法解析的参数渲染为 `[unparseable arguments]`。
- 持久摘要最多 64 条；更早的观察被丢弃并设置 `truncated: true`。
- 任何能读任务的调用方都能看到 trace metadata。只对可信对端开启。

## 版本

上述字段的 breaking 变更必须使用新 URI（`.../v2.md`）。不认识该 URI 的客户端会忽略
卡片宣告与 metadata。
