# dsh-trace/v1

**English** · [中文](v1.zh.md)

Optional A2A extension for bounded, redacted tool-call observations.

- **URI:** `https://github.com/hanphone/dsh-a2a/blob/main/docs/extensions/dsh-trace/v1.md`
- **Required:** no
- **Carrier:** `metadata` only
- **Default:** off

The extension never changes the task's deliverables. It does not add artifacts,
does not modify `Task.history`, and is never read by the outbound tool renderer.

## Activation

The agent advertises the extension in `AgentCard.capabilities.extensions` only
when its instance policy allows it. A client activates it per request:

```http
A2A-Extensions: https://github.com/hanphone/dsh-a2a/blob/main/docs/extensions/dsh-trace/v1.md
```

A successful response echoes the activated URI in the same header. A server that
does not allow the extension ignores the request (the extension is optional).

## Data

Live observations are carried incrementally on
`TaskStatusUpdateEvent.metadata[URI]`:

```json
{
  "event": {
    "callId": "call-1",
    "tool": "read_file",
    "phase": "start",
    "status": "running",
    "argsPreview": "{\"path\":\"a.txt\"}",
    "timestamp": "2026-10-25T10:00:00.000Z"
  }
}
```

The settled task carries a bounded summary on `Task.metadata[URI]`:

```json
{
  "calls": [
    {
      "callId": "call-1",
      "tool": "read_file",
      "phase": "start",
      "status": "running",
      "argsPreview": "{\"path\":\"a.txt\"}",
      "timestamp": "2026-10-25T10:00:00.000Z"
    },
    {
      "callId": "call-1",
      "tool": "read_file",
      "phase": "end",
      "status": "ok",
      "durationMs": 12,
      "timestamp": "2026-10-25T10:00:00.012Z"
    }
  ]
}
```

### Fields

| Field | Type | Meaning |
|---|---|---|
| `callId` | string | Tool-call correlation id |
| `tool` | string | Tool name |
| `phase` | `start` \| `end` | Observation phase |
| `status` | `running` \| `ok` \| `error` \| `unknown` | `running` only on start; `unknown` when the turn ended without a result |
| `durationMs` | integer ≥ 0, optional | End-to-end duration from the session event times |
| `argsPreview` | string, optional | Redacted, truncated argument preview; start events only |
| `timestamp` | ISO 8601 string | Event time |
| `calls` | array | Durable summary; at most 64 observations |
| `truncated` | boolean, optional | The summary dropped older observations |

## Privacy and bounds

- Never include raw tool arguments, tool results, file contents or reasoning.
- `argsPreview` redacts keys matching token/secret/password/api-key/
  authorization/cookie/credential/private-key and truncates the serialized value
  to 200 characters.
- Unparseable arguments render as `[unparseable arguments]`.
- The durable summary keeps at most 64 observations; older observations are
  dropped and `truncated: true` is set.
- Trace metadata is visible to any caller that can read the task. Enable it only
  for trusted peers.

## Versioning

A breaking change to the fields above requires a new URI (`.../v2.md`). Clients
that do not understand this URI ignore both the card declaration and the
metadata.
